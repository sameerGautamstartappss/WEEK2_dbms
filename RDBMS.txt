Database - An organized collection of data. A method to manipulate and acess the data.
Database management system is used to manage, fetch and manipualte data in the database.
MYSQL, ORACLE, etc -> (DBMS, Database)

Note - Data of the digital age can be categorized into operational and analytical data.
- Operational data is used for day to day treansactiona and needs to be fresh-for example product inventory and bank balance. Such data is captured in real-time using Online Transaction Processing (OLTP) systems.

- Businesses use analytical data to gain insights into customer behaviour, product performance, and forecasting. It includes data collected over a period of time and is usually stored in OLAP (Online Analytical Processing) systems, warehouses, or data lakes.

Most companies need both OLTP(operational) and OLAP(analytical) systems to store their data and can use a relational database, non-relational database, or both to serve their business purposes.
RDBMS - Relational Database Management System
    - part of the database that allows you to interact with the data.
    - software that manages a relational database.
    - A collection of smaller programs that work together to let developers manage data in tables easily, without needing to know its physical storage location.
    - SQL is the programming langauge that helps to interact with the relational database management system.

Data Storage:
    - RDBMS allows the user to create relational tables, which are the structutre for storing and retrieving data.
    - This storage module works at the lowest level of the database.
    - Takes care of the way data is organized on the disk.
    - Takes care of the location where the data is stored on the disk.
    - Takes care of the movement of the data when you make some update to some values.
    - How and when empty spaces are handled when you delete data.
    - In a relational database, all the data and tables are stored into what are called "database files"

A table utilizes columns to define the types of informations being stored and rows to hold actual data.

Each table contains a column that contains a unique values, referred to as the primary keys.

This primary key can be used in other tables to establish relationships between them.

When the primary key from one table is used in another table, the corresponding column in the second table is known as the foreign key.

The most common way of interacting with relational database systems is using SQL (Structured Query Language).

Developers can write SQL queries to perform CRUD (Create, Read, Update, Delete) operations.

A table can have only one primary key, but that primary key can consist of one or more columns.

How to know in which database we are?

-> select database();

-> Deleting a database
    DROP DATABASE <database_name>
    
-> Creating a table
    A table is a collection of related data organized in rows and columns.

    CREATE TABLE <table_name> (
        <column_name>  <data_type>, 
        <column_name>  <data_type>
    )

    varchar(100): 100 characters long data.

-> To see all available tables in a Database

    SHOW TABLES;

-> Checking your table 

    DESC <table_name>

-> Adding data into a table 

    INSERT INTO <table_name>(<column_name>, <column_name>) VALUES (<value1>, <value2>);

    Note - When you add value in the default sequence:
    INSERT INTO <table_name> VALUES (<column1_value>, <column2_value>);

-> Inserting multiple data into table

    INSERT INTO <table_name> VALUES (<column1_value>, <column2_value>), (<column1_value>, <column2_value>), (<column1_value>, <column2_value>), (<column1_value>, <column2_value>, (<column1_value>, <column2_value>));

-> Reading data from table
    - Read or print a table 
        SELECT * FROM <table_name>; 
    - Read or print a column data
        SELECT <column_name> FROM <table_name>;
    - Read or print multiple columns
        SELECT <column_name>, <column_name> FROM <table_name>;

    Note - Select query is used for reading data from a query and printing data from a query.

-> Read or print data based on given condition:

    SELECT * FROM <table_name> WHERE <column_name>=value;

-> Modify/Update data into a table:

    UPDATE <table_name> SET <column_name> = value WHERE <column_name>=value;

-> Delete data from a table 

    DELETE FROM <table_name> WHERE <column_name>=value;

-> How to set "NOT NULL" attribute in a table ?

    CREATE TABLE <table_name>(
        <column_name> <data_type> NOT NULL,
        <column_name> <data_type> NOT NULL  
    );
